# 📄 Project Retrospective

## What Went Well

The project came together well overall, and I found the support from Codex and the project resources helpful throughout development. The JavaScript Mastery materials were useful, and it was clear that the supporting structures outside the videos have improved, making the development process easier to follow and apply.

---

## Challenges & Trade-offs

One of the main challenges was that Codex sometimes went off track or generated code that was not fully correct. This created issues later in the project and meant I had to spend extra time checking, debugging, and fixing problems. The main trade-off was that AI support helped me move faster, but it also required careful review to make sure I still understood the code and that the solution was reliable.

---

## Key Learnings

I learnt more about working with modern integrations such as Clerk, and how authentication can now be handled through external services rather than being built completely from scratch. While this feels a little disappointing from a learning perspective, it also reflects how modern development is moving towards using reliable third-party tools. I also learnt more about AI integration, API usage, and how these services can be combined to create more interactive user experiences.

---

## Skills Improved

- AI usage and prompting
- Debugging AI-generated code
- Authentication using Clerk
- Environment variable management
- Component-based development
- Git branches and commit messages

---

## Industry Practices Applied

Industry practices applied included using Git branches and clear commit messages, separating concerns through reusable components, validating form inputs with Zod, managing authentication through Clerk, using environment variables for secure configuration, and testing features locally before deployment. The project also followed an iterative development process by building, testing, debugging, and improving features over time.

---

## What I’d Do Differently

In future projects, I would rely on AI less during the core learning stages. I want AI to support my development, not replace the learning process. I would spend more time trying to understand and solve problems myself first, then use AI to review, explain, or refine my approach.

---

## Next Steps

The project could be improved further with additional polish, stronger error handling, and more refinement of the user experience. However, I may leave it as it is for now and treat it as a completed learning project before moving on to the next stage of development.
